# Eventos

Os arquivos procEventoNFe são eventos relacionados a NFe. Os eventos tem um schema generico e cada tipo de evento tem um schema específico dentro da tag `detEvento`, que contém o conteúdo xml da mensagem de entrada do evento. Os scheme genérico está definido na tabela abaixo. A coluna **Armazenar** define se o elemento deve ser armazenado no modelo Odoo ProcEventoNFe. Os elementos da mensagem de entrada que se repetem na mensagem de saída devem ser armazenados num campo só, de maneira que o campo está marcado com S na mensagem de entrada mas marcado com N na mensagem de saída
